# Production embed path map (fingerprint 615ae97d2350)

The `engine` builds each ligand from its input SMILES and donor groups. The generated ligand is later placed as a rigid body and optimized only through the solver's declared joints. Bond lengths, angles outside bend joints, ring conformations, stereochemistry and all other local coordinates from this path are therefore frozen.

| Route | Trigger | Embed/refinement behavior | What remains frozen downstream |
|---|---|---|---|
| Plain ETKDG | No special chelate/cap route applies, or chelate embedding returns `None`/fails; `embed="etkdg"` skips force-field refinement | ETKDGv3, seed 42 by default; optional MMFF and then GFN2 when selected | Bond lengths, non-joint angles, ring shape, stereo and H geometry, except joints explicitly exposed by IK |
| Chelate distance bounds | Default `chelate_embed=True`, at least two single-atom donors or another capping/EZ reason, no explicit H | Bounds donor pairs by `D_MIN`, `R_MD`, and small-ring bite-angle ceiling; tries up to `N_TRY` extra conformers if first violates; used as MMFF flat-bottom constraints | Same frozen coordinates; donor-pair geometry is also frozen unless solver joints alter it |
| Temporary H/valence caps | Single-atom kappa donor has missing valence/charge/radical (except group-13 ate atoms and excluded aromatic systems) | Neutralize/complete donor valence with temporary H, =CH2 or #CH; cap is dropped after embed; MMFF, then optional GFN2 | Original ligand internals and H placements are fixed to capped-surrogate-derived coordinates |
| Bound surrogate | `bound_surrogate=True` and a B/Al/Ga kappa donor is double-bonded to a positively charged neighbor | Rewrite the free bond/charge and add H at the donor; embed/refine; map heavy atoms and shared H back; discard cap | Rewritten donor neighborhood's distances/angles, then all other frozen coordinates |
| Carbene/ylide handling | `carbene_ylide=True` and eligible kappa carbene donor | Cap logic treats donor valence; carbene next to a neutral N/O/S lone-pair center can be represented as an ylide/iminium during the embed | Donor-neighbor bond order and resulting geometry are retained in input graph coordinates |
| GFN2 refinement | `embed="gfn2"` (production default) after ETKDG/MMFF or chelate/surrogate embedding | `xtb --gfn 2 --opt crude`; donor-set pair distances held with xTB constraints; cache keyed by graph, donor set and starting coordinates. Failure warns and silently retains MMFF geometry | Refined covalent geometry, non-DOF angles, pucker and H placement; donor geometry held near its input embed values |
| MMFF fallback | GFN2 fails or `xtb` is absent; also the selected `mmff` method | Production warns `GFN2 embed refinement failed` and keeps MMFF geometry. MMFF can be a no-op if it lacks complete parameters | Same frozen coordinates, with potentially unrefined or poorly typed atoms |
| E/Z variants | Unspecified E/Z on donor-chelate path gets a ring-aware choice; `ez_enumerate=True` enumerates up to `EZ_MAX_BONDS` eligible unassigned double bonds in solve variants | Fix donor-chelate E/Z from ring path; otherwise enumerate combinations; too many bonds fall back to embed's assignment | E/Z and resulting local geometry are fixed in each solve variant |

No production behavior is changed in this study. `profile.py` registers `embed`, `deterministic_embed`, `chelate_ez`, `carbene_ylide`, `bound_surrogate`, and `ez_enumerate`; helper-level constants in `chelate_embed.py` and `engine.py` implement the resolved defaults.
