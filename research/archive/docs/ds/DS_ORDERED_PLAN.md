# DS investigation: consolidated remaining work

Proposed sequence for owner review, 2026-11-10. This records the discussion;
it does not authorize a billed job or replace an already frozen evaluation
contract. Completed Checkpoint A is documented in DS_DATA_CHECKPOINT_A.md.
New protocols must be committed before their results are opened.

## Scope and working rules

One package: source/extraction correctness, reproducible DB construction,
sampling stability, fit sensitivity, and enough downstream evidence to
isolate failures. Retain the existing S/P initialization candidate. A new
solver intervention is conditional on demonstrated failure attribution.

Keep the current production stereo configuration fixed. No NN development,
additional stereo development, broad coverage redesign, extra degrees of
freedom, or new optimizer search. Record findings relevant to those tracks
as reproducible handoff evidence.

Vary one factor at a time or use a declared factorial comparison. Preserve
historical gate failures and raw records. Develop only on eligible cal/tail
cases. Locked evaluation remains in auditor custody. Use tools.run, matched
machine/GPU controls and the control cache, and parent-clustered bootstrap
intervals for parent comparisons. Each billed job needs the owner's go
with its QOS and a current estimate.

## 5. Run fixed-pool attribution and fit sensitivity

Hold generator/runtime settings fixed and vary only the DB first. Freeze
candidate pools before stress results. Historical pools are usable only for
compatible unchanged targets; repaired targets require new common-target pools.
Use the same independent energy evaluator across comparisons.

Development cases: LUQVOK, SESWIZ, LIPDEU, YABYEJ, LOPJEF, ZAQNUE, HOXJUZ,
USAPOU, repaired UMUBAF, MIGTEE and EFOXII, subject to the existing development
eligibility rules. Start the stress pilot with the implicated LUQVOK Q1 and
LIPDEU QO populations; expand after measuring cost and verifying exact refits.

Use the registered one-parent and ceil(1%, 2%, 5%) doses, 32 random replicates,
64 parent-bootstrap designs, seed 11, and bounded 0.02 A source perturbations.
LnQM siblings are one independent parent. Mechanisms are observed source errors,
whole-parent removal and source-coordinate perturbation. Perform isolated-fit
attribution and coherent whole-parent changes across dependent quantities.

Measure fit stability and selected-row score margin, independent energy and
coordination. Severe failure is >25 kJ/mol adverse top-1 change or newly broken
coordination on at least two of paired seeds 11–13. Report single-seed events,
execution failures, complete dose-response rates with Wilson intervals, and
first tested failing fraction or censoring at the maximum tested dose. These
are conditional tested sensitivities, not universal DB cleanliness guarantees.

Output: ranking/fit counterexamples and confidence summaries explicitly labeled
fixed-pool coverage. A missing good structure is a generation question.

## 6. Confirm generation and test the existing S/P candidate

First compare the selected corrected DB with production using current
initialization. Then test current initialization versus existing P/S on the
selected corrected DB and preselected damaged trials. Do not cross every DB
with every start/beam variant. P/S is start_kabsch + start_kabsch_pivot; leave
other runtime settings fixed. Measure top-1, available energy floor,
coordination, coverage, diversity and matched compute.

Include JEGPUJ/SIVBUV as a small placement/collapse diagnostic supplement only
after confirming source and development eligibility and freezing their role.
They exercise the existing P mechanism beyond the new DB-loss cases.

For selected failures, record initial targets/poses, assignments, source mode,
candidate identities and enough pre/post-pruning trajectory evidence to locate
loss. If needed, cross clean/perturbed initialization with clean/perturbed
objectives using replayed starts. This is a diagnostic, with all identities
recorded, not a silently mixed production configuration.

Output: measured P sensitivity and attribution to starts, optimization,
pruning or final ranking, with reproducible counterexamples.

## 7. Address only demonstrated remaining mechanisms

| Evidence | Next narrowly scoped test |
|---|---|
| Source or extraction error | Generic correction/eligibility rule, re-extraction and attributed refit |
| Valid population change destabilizes a broad fallback | Inspect contributions; test justified chemistry-conditioned pooling |
| Perturbed objective fails with clean starts | Responsible fit/scoring sensitivity, before adding more starts |
| Perturbed starts fail with a clean objective | Target-mode allocation or complementary starts at matched compute |
| Useful candidates lost during pruning | Candidate retention or a targeted beam comparison |
| Useful candidates retained but selected poorly | Responsible ranking terms/fits |
| Reasonable diverse starts collapse during optimization | Trace the responsible optimization/culling mechanism |

Freeze the DB for a solver-only comparison. Use one baseline and one
mechanism-specific implementation at a time, with actual compute recorded.
Keep this within the same investigation; no broad variant sweep or new NN/
stereo work. Any conditional new implementation gets a frozen comparison
before results. Repeat only the checks justified by the changed paths.

Output: a justified candidate, or an explicit unresolved failure plus a
minimal next experiment. Checkpoint: audit sensitivity/P evidence and decide
the candidate before full qualification. Severe failures block qualification.

## 8. Run the corrected qualification gate

Use identical audited targets for both arms and a fresh target-aware control
identity, reusing valid controls through the standard cache/canary procedure.
Keep ambiguous/unrepaired cases visible under the predeclared source-based
disposition. Preserve historical D/DS outcomes separately. Do not reuse
old generated structures as repaired-target outputs.

Apply the frozen energy, guard, catastrophic, coordination/coverage,
diversity, runtime and failure-accounting requirements, with parent-clustered
intervals. Existing P is included only if the preceding evidence supports
its candidate role. Locked qualification/reserve access follows auditor
custody and its own authorization. Failed gates remain failed. Owner decides
fold-in; agents do not merge, push or overwrite production DBs/goldens.

Output: qualification verdict and a reproducible integration/handoff package.

  attribution and archived reproduction. Keep reproduction exceptions and
  quantity-specific charge-filter effects open; use an additional declared
  ablation if consequential changes remain unexplained. Locked exclusion is
  custody, not a candidate model knob.

- Additional physical-Q6 variants: not prioritized for these losses after
  the completed ablation retained them.
- Broad union-beam, seed-reallocation, ring/DOF and optimizer development:

  evidence is retained; no assumption that more diversity improves ranking.
- NN/stereo implications: export source-quality categories, fit support and
  pooling dependencies, failed perturbations, candidate/trajectory evidence
  and hypotheses. No model training or stereo expansion in this package.

## Exit state

Deliver corrected/reviewed extraction with explicit unresolved populations,
reproducible and attributed DBs, measured sensitivity, a decision on existing
P/S, any justified minimal follow-up, and a fair qualification verdict.
